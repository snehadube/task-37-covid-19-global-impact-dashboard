# Data notes

The included CSV is a filtered extract of the OWID COVID-19 dataset, selected to keep the repository small enough for direct GitHub browser upload. It includes the World aggregate, available continent aggregates, and 12 selected countries. Missing values are retained. The original source uploaded by the user contains 350,085 rows and 67 columns; do not upload that 92 MB raw CSV through GitHub's browser UI. See the source documentation linked in README.
